# Artwork and asset provenance

The original fourteen portraits, unified bust, skyline and earlier card landscapes were generated with the built-in `image_gen` tool on 2026-11-09, using the mockup and individual crops for guidance. Four newly approved footer characters were generated separately on 2026-11-10; their exact prompts and recognition checks are in [`footer-character-art.md`](footer-character-art.md). All eighteen portraits are independently addressable, with retained numbered PNG masters and WebP variants in `src/assets/art/`. Unframed portraits and the unified bust use lossless 1280 × 1920 derivatives with transparent glow margins; CSS provides bottom fades. Rei and Usagi retain their separate CSS window frames. The three active game-card backgrounds now use complete in-game/official screenshots rather than separate strips; sources, processing and rights notes are in [`game-card-art-provenance.md`](game-card-art-provenance.md). Former generated and cropped versions are retained. No part of `mockup.png` is embedded as the page or its background.

The mockup and `docs/mockup-reference.md` guided character traits, palette and crop. AI-generated portraits depict copyrighted fictional characters; this records their origin, not a grant of franchise rights. Public and commercial reuse rights remain unresolved and need review by the site owner.

The four footer additions are `shantae-2.webp`, `marie-rose-2.webp`, `oguri-cap-2.webp` and `tamamo-cross-2.webp`. Each has a separate `-1.png` master and a lossless padded derivative. Shantae has her purple ponytail/red genie outfit; Marie Rose has blonde twin tails/blue fighting outfit in anime style; Oguri has the giant rice bowl and funny eating face; Tamamo provides the separate chibi reaction. Their full prompt set and generation identifiers are retained in the linked footer-art record above.

## Fonts

The page requests Barlow Condensed, Exo, Mr Dafoe, Permanent Marker, Rajdhani and Racing Sans One from Google Fonts through the stylesheet import in `src/assets/site.css`, with local system fallbacks. Font files are not copied into this repository. The font source is [Google Fonts](https://fonts.google.com/); the page depends on that external font host for the named faces, but remains readable if it is unavailable. Verify the current font-specific license terms before bundling or redistributing the font files.
