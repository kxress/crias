# Artwork and asset provenance

Character portraits, the unified bust, skyline and earlier card landscapes were generated for this site with the built-in `image_gen` tool on 2026-11-09, using the mockup and individual reference crops for guidance. Current portrait variants are independently addressable transparent WebP files; each generated PNG master is retained in `src/assets/art/`. Previous and alternate variants remain intact under their original or numbered filenames. The active twelve unframed portraits and unified bust use lossless ImageMagick WebP derivatives with the original art centered on a 1280 × 1920 canvas, adding transparent margins of 128px horizontally and 192px vertically; CSS sizes and offsets preserve their former visible silhouette. Rei and Usagi retain their framed versions. On 2026-11-10 the three active card header images changed to cropped in-game/official screenshots; their source, crop and rights notes are in [`game-card-art-provenance.md`](game-card-art-provenance.md). Former generated card headers remain as `*-scene-1.webp`. No element from `mockup.png` is embedded or used as a page background.

The mockup and `docs/mockup-reference.md` guided character traits, palette and crop. AI-generated portraits depict copyrighted fictional characters; this records their origin, not a grant of franchise rights. Public and commercial reuse rights remain unresolved and need review by the site owner.

## Fonts

The page requests Barlow Condensed, Permanent Marker, Rajdhani and Racing Sans One from Google Fonts through the stylesheet import in `src/assets/site.css`, with local system fallbacks. Font files are not copied into this repository. The font source is [Google Fonts](https://fonts.google.com/); the page depends on that external font host for the named faces, but remains readable if it is unavailable. Verify the current font-specific license terms before bundling or redistributing the font files.
