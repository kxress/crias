# Proposal

## Why

The current page displays a mockup but does not help players join or use the private network. A product contract is needed that serves those journeys while retaining a recognizable community identity without treating a historical image as an acceptance test.

## What Changes

- Introduce a Brazilian Portuguese, responsive static website explaining the private offering and directing visitors to onboarding and server details.
- Document manual NetBird onboarding, a maintainable directory of verified game connection details, and accessible copy interactions.
- Establish a cohesive neon arcade identity, accessibility, and reliable presentation without prescribing a screenshot composition.
- Gate publication of operational values on confirmation by the network operator; do not infer live availability.
- Exclude network administration, automatic invitations, accounts, monitoring, payments, and community-management systems.

## Capabilities

### New Capabilities

- `website-experience`: Site purpose, navigation, visual identity, accessibility, responsiveness, and presentation resilience.
- `private-network-onboarding`: Prerequisites and manual NetBird access journey.
- `server-discovery`: Game grouping, reliable connection records, and publication safeguards.
- `connection-copy`: Accessible copying and failure recovery for connection values.

### Modified Capabilities

None. The checkout has no current canonical capabilities; the staged removal of the historical visual spec is intentional and is not restored by this change. Any future existing canonical specifications remain authoritative unless explicitly changed.

## Impact

Eventual implementation affects the static page, supporting content/data and assets, and possibly the Pages workflow if a build is introduced. It requires no backend or NetBird API. The operator must confirm connection data, invitation instructions, and permissions for any third-party assets before publication. This proposal changes no application code or infrastructure.
