# Project Overview

This repository is a GitHub Pages project for a browser game. `mockup.png` is the current visual reference.

## General Guidelines

- Build the project as a static site that can be hosted by GitHub Pages; do not depend on a server runtime.
- Keep routes, asset URLs, and build output compatible with the repository's GitHub Pages deployment configuration.
- Preserve the visual intent of supplied mockups when implementing the game.
- Inspect existing files and follow their conventions before choosing tools or adding dependencies.
- Keep changes focused and verify site behavior with the available project commands.
