JOGA COM A GENTE

⌁ Como entrar

O acesso é privado. A página explica o caminho, mas não cria convites.

  1. 01

    Instale o NetBird

    Baixe o cliente oficial para seu computador. No primeiro acesso, siga as opções apresentadas pelo próprio NetBird.

    Abrir instalação oficial ↗
  2. 02

    Configure a rede

    O endereço de gerenciamento é a URL usada pelo cliente NetBird para encontrar o serviço que administra a rede privada. No primeiro acesso, o cliente permite usar o NetBird Cloud ou informar a URL de uma implantação própria.

    ◎ Configuração indisponível enquanto aguarda confirmação do operador.

  3. 03

    Peça seu convite

    Uma pessoa da Crias ou um contato autorizado libera o convite manualmente. Este site não emite nem automatiza convites.

    ✉ Canal de contato ainda não confirmado.

  4. 04

    Conecte à rede privada

    Depois de receber o convite, conclua o acesso no NetBird e conecte-se à rede. Sem a rede conectada, os hosts privados não podem ser usados.

  5. 05

    Escolha seu jogo

    Use o host, a porta e o protocolo da mesma entrada no diretório. Só exibimos dados confirmados pelo operador.

    Ver diretório de jogos ↓
